このフォルダには、2026-08-09の管理画面中心への方針変更で保留したコード、ワークフロー、データ、資料を保存する。旧フォルダ名は `old/` だったが、役割を明確にするため `archive/` へ変更した。

## 重要

- ここにあるファイルは現在の実行対象ではない。
- `.github/workflows/` と `scripts/` へ戻すだけで有効化しない。
- 再利用時は現行の管理画面仕様、承認、安全、テスト基準に合わせて再設計する。
- 過去のAPI、モデル、Secret名、外部サービス条件は古い可能性がある。
