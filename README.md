# my-game-blog

このリポジトリは、公開ブログと運営ツールを役割別に分けている。

| フォルダ | 役割 |
|---|---|
| `blog/` | Hugoブログ本体。公開記事、デザイン、画像、テーマ |
| `admin/` | これから作るローカル管理画面 |
| `tools/publishing/` | 記事の同期、校正、プレビュー、検査、公開 |
| `tools/backup/` | 暗号化バックアップと復元用ツール |
| `config/` | 編集方針、校正表示、バックアップ設定 |
| `docs/` | 現在の仕様、ロードマップ、操作手順 |
| `archive/` | 保留した旧コードと過去資料。実行対象外 |
| `var/` | ビルド結果、一時ファイル、過去の生成物。Git管理対象外 |

最初に `docs/README.md` と `AGENTS.md` を確認する。
