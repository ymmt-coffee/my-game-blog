# Phase H アクセス解析実装報告

作成日: 2026-08-11
状態: ローカル範囲完了・外部接続保留

## 実装した範囲

- 集計済みCSVを管理画面から取り込める。
- 7日、30日、90日の閲覧数と延べ訪問者数を表示する。
- 同じ長さの直前期間と増減を比較する。
- 日別閲覧数、よく読まれたページ、簡単な確認候補を表示する。
- CSVひな形を管理画面から取得できる。
- 取込履歴をSQLiteへ記録する。

## CSV形式

必須列は `date,path,views,visitors` である。日付は `YYYY-MM-DD`、pathはクエリ文字列を含まない `/` 始まりの公開ページパスとする。

同じデータ元、日付、ページを再度取り込んだ場合は新しい値へ置き換える。追加加算しないため、同じCSVの再取込で数値が倍にならない。

## 安全・プライバシー

- IPアドレス、Cookie、ユーザーエージェント、参照元の生データを保存しない。
- CSVはUTF-8、2MB以下、10,000行以下に制限する。
- 不正な日付、負数、重複、クエリ文字列を検出した場合は全体を取り込まず停止する。
- SQLiteには日別・ページ別の集計値だけを保存する。
- テストでは外部サービスへ接続しない。

## 保留事項

現在の公開サイトにはUmami、Google Analytics、Plausible用の無効な受け口があるが、providerと識別子は空である。次は次の事項についてユーザー判断が必要となる。

1. 使用する解析サービス
2. 公開サイトへ計測タグを追加するか
3. Cookieや同意表示が必要な構成にするか
4. APIによる自動取得を行うか
5. 自分の閲覧を除外する方法

外部サービスの選定と接続までは、本実装では行っていない。
