- 月〜日の週間ルーチンと、木曜日の情報収集ボタン

## 週間ルーチン

- 日曜日までに次のレビュー対象ゲームを決める。
- 翌週の日曜日までプレイとレビュー執筆を進める。
- 完成したレビューは、その次の水曜日に予約公開する。
- 新作・セールは木曜日に情報収集し、日曜日に公開する。
- 2本目以降のレビューは余裕がある場合だけ追加する。

## 安全境界

- AIは記事本文を自動変更しない。
- 購入、公開、X投稿は人の明示操作なしに行わない。
- APIキー、token、Steam ID、Cookieなどを画面、DB、ログ、Gitへ保存しない。
- `review-report.md`、`var/`、バックアップ複製、環境変数ファイルをcommitしない。
- テストから外部サービスを呼ばない。
