# Phase E 校正・プレビュー・公開 実装報告

作成日: 2026-08-09

状態: 実装・ローカル検証完了

## 実装内容

- Geminiによる構造化校正と、本文を自動変更しない結果表示
- 指摘ごとの採用・見送り記録
- 現在の原稿ハッシュと校正対象ハッシュの照合
- 一時contentを使うHugoプレビュー
- 必須項目、秘密情報、画像、内部リンク、Hugo本番ビルド、生成HTMLの公開前チェック
- 記事ハッシュへ結び付けた15分間有効・一回限りの承認
- 対象slug入力を必要とする最終確認
- 正本と公開コピーだけのstage・commit・push
- GitHub Pages runと公開URL HTTP 200の確認

## 安全策

- 校正結果は `var/admin/reviews/` に保存し、記事bundleと公開対象へ入れない。
- AI入力に秘密情報らしい値があれば送信前に停止する。
- AI出力は構造と危険なHTMLを検査し、コマンドとして実行しない。
- プレビューと公開前チェックは一時コピーを使い、正本を変更しない。
- 既存stage、公開コピーの未コミット変更、対象外stage、ハッシュ変更、校正不一致、承認不足で停止する。
- commit前の失敗は公開コピーを元へ戻す。commit後にpushが失敗した場合は、復旧可能なローカルcommitとして明示する。
- テストから実AI、GitHub、Pagesを呼ばない。

## 検証

- fake AI校正で本文が変わらないこと
- 校正レポートが記事bundleへ入らないこと
- 指摘の採否が本文を変更しないこと
- 原稿変更で古い校正と承認が無効になること
- Hugo失敗時に原稿が維持されること
- 承認なしでGit・外部通信が呼ばれないこと
- stage混入時にcommit・pushしないこと
- 実Hugoによる一時記事のプレビューと公開前チェック成功

実装作業中に実記事のAI校正、commit、push、Pages公開は実行していない。
