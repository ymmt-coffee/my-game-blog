# Phase D 記事テンプレート 実装報告

作成日: 2026-08-09

状態: 実装・ローカル検証完了

対象: 3カテゴリーのテンプレート、種類別入力、注意表示、必須項目検査

## 実装結果

- プレイ途中記、新作・セール5選、月次レビューエッセイの本文雛形を追加した。
- 新規作成画面でカテゴリーごとの用途と注意点を表示する。
- タイトル、概要、著者などの共通項目を必須とし、プレイ途中記だけプレイ時間を必須にした。
- 編集画面で現在のfront matterを検査し、「入力済み」または不足項目を表示する。
- カテゴリーを変えても既存本文を自動置換しない。プレイ途中記以外へ変えた場合だけ不要な `play_time` を除く。
- 既知項目を更新しても、将来追加された未知のfront matterキーを保持する。

## 下書き保存の扱い

既存記事や執筆途中の記事を壊さないため、必須項目に不足があっても下書きの表示・保存は可能にした。不足は編集画面に明示する。Phase Eの公開前チェックでは、同じ検査結果にエラーが残る記事の公開を停止する。

## テンプレート内容

### プレイ途中記

進行状況、印象、次回の目標の見出しを用意する。プレイ時間をfront matterへ保存する。

### 新作・セール5選

選定方針、5本分の見出し、発売日・期間、価格、日本語対応、情報源の確認欄を用意する。未プレイ作品は未プレイと明記する注意を表示する。

### 月次レビューエッセイ

月のテーマ、心に残った体験、考察、来月への見出しを用意する。

## 安全性

- 記事は引き続き通常のMarkdownファイルを正本とする。
- 原子的保存、履歴、競合検出、自動保存、画像非上書きを維持した。
- 既存本文をテンプレートで自動上書きしない。
- 校正、プレビュー、投稿、予約、外部送信、commit、pushは実装・実行していない。
- ローカルに作成済みの記事と画像は変更していない。
- デスクトップアイコンは実行中の版を確認し、更新後だけ管理画面専用プロセスを自動再起動する。PowerShell画面は表示しない。

## テスト

- 3カテゴリーごとのfront matterと本文雛形
- プレイ途中記だけのプレイ時間必須判定
- 日本語とYAML特殊文字
- 未知front matterキーの保持
- 必須項目不足の表示とファイル非変更
- 新規作成画面のカテゴリー説明
- Phase B/Cを含む管理画面回帰テスト
