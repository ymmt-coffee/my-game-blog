遊ぶ。書く。
運営はAIと仕組みに任せる。

やまもとがゲームプレイと文章執筆に集中し、企画選定・校正提案・公開・SEO・分析・SNS運用をAIと自動処理が担うための確定仕様。

最優先原則 文章はやまもとが書く。AIは本文を書き換えず、企画・指摘・整理・分析・通知を担当する。

編集方針

アクセスと収益を意識しつつ、文章を書く趣味として無理なく続ける。攻略メディアではなく、面白いPCゲームを探す人と文章を読む人の双方へ届ける。

WEEKLY

プレイ途中記

週1本。最低5時間を目安に、その週に遊べるだけ遊んで執筆。完走レビューとはせず、プレイ時間を明記する。星評価や明確な購入判定は載せない。

MONDAY

新作・セール5選

翌月曜から日曜までの新作と20%以上のセールから5本を掲載。AIが公式情報を基に作成し、やまもとが日曜24時までに短い私感を追記する。

MONTHLY

レビューエッセイ

余力がある月に公開。フルプレイしたゲーム体験を題材に、私小説的な読み物として自由に書く。アクセスやSEOを強く要求しない保護領域とする。

扱う作品

  • PC / Steam中心
  • インディー・小規模開発を優先
  • 特に関心が高い場合は大手作品も対象
  • 英語作品は日本の一般読者が抵抗を感じにくい範囲
  • 一般的な戦闘・ホラー・軽度の流血は対象

扱わない領域

  • 攻略を主目的とする記事
  • 成人向け作品
  • 強い残虐表現を中心とする作品
  • リークや確認できない発売情報
  • 具体的なネタバレ（避けられない場合は冒頭警告）

AI編集長

プレイ状況、記事在庫、検索機会、更新時期を基に、今週書く記事とリライトの優先順位を決める。

AI編集者 / SEO

タイトル、見出し、検索意図、説明文、内部リンク、古い情報の可能性を公開前に確認する。

分析担当AI

Search Consoleとアクセス解析を週次集計し、伸ばす記事・直す記事・止める企画を提案する。

SNS運用もAIへ

ブログ記事を起点に、投稿企画・文面・画像案・予約・効果測定・再利用までを一つの流れにする。フォロワー数より、記事への質の高い流入と読者との信頼を評価する。

投稿を作る

記事公開時に、告知、役立つ小ネタ、プレイ中の発見、後日の再紹介という複数の切り口をAIが生成。各SNSの文字数と文化に合わせて書き分ける。

投稿を配信する

公開直後、翌日、1週間後などに予約投稿。投稿ID、記事ID、キャンペーン情報を記録し、どの投稿が読者を連れてきたか追跡する。

反応から学ぶ

表示、クリック、保存、反応、ブログ滞在を集計。反応の良いゲーム・切り口・時間帯を次の記事選定と投稿計画へ戻す。

AUTOMATIC

自動化してよい範囲

  • 公開済み記事の告知と再紹介
  • ユーザーが確認済みのプレイメモの再構成
  • 定型の更新通知、訂正通知、週次まとめ
  • 反応データ収集と投稿案の改善
APPROVAL REQUIRED

  • 未確認の攻略情報、リーク、発売前情報
  • 強いネタバレ、権利関係が不明な画像
  • 広告、提供、アフィリエイトを含む投稿

X

日本のゲーム話題との相性を想定した主配信先。APIは従量課金で、URL付き投稿は公式価格上コストが高いため、投稿頻度と月額上限を先に決める。

Bluesky

短文投稿の第2配信先候補。X向け文面の単純コピーではなく、タグや書き出しを調整して配信する。

YouTube / Shorts

後期拡張。動画素材がある場合に、AIがタイトル、説明、章、短尺構成を作る。自動アップロードは監査・権利確認を経て導入する。

AI編集長の選定

毎週3本を提示し、ゲーム名、選定理由、価格、日本語対応、Steam評価、検索・話題性、やまもと適合度を表示する。

優先順位 1–3

  1. 発売直後などの話題性
  2. 検索需要
  3. やまもとの好みとの一致

優先順位 4–6

  1. 他ブログの情報不足
  2. Steamでの評価
  3. 価格の安さ

優先順位 7–9

  1. 日本語対応
  2. 週次記事への適性
  3. 月次エッセイへの発展性

通常購入予算は月15,000円。特に注目すべき作品がある月のみ最大30,000円。候補は原則未所有作品とし、Steamライブラリとウィッシュリストを参照する。

  • 下書き・テスト記事の誤公開

レポートなし・古い結果、誤字、SEO、構成提案は警告に留め、確認後は公開できる。

費用の目安

静的サイトとWebhook中心なら固定費を抑えられる。AI利用量だけ予算上限を設定する。

項目想定
Hugo / GitHub Pages / Discord Webhook無料
Search Console / GA4 または軽量解析無料枠中心
独自ドメイン年 約1,000–4,000円
AI API（週次指示・記事レビュー）月額上限内で従量
SNS投稿API / 予約投稿サービス媒体・頻度により従量または月額
常駐Discord Bot初期は不要

AI・X API・問い合わせフォーム等の自動化費用は合計月3,000円を上限とする。80%で警告し、上限到達時は臨時SNS投稿、詳細分析、臨時調査、通常の再紹介の順で停止する。
