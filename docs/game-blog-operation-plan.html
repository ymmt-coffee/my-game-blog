game logs ローカル管理画面

Obsidian、Discord、個別コマンドに分散した操作を、PC内だけで動く管理画面へ集約する。

最初の完成目標: 管理画面だけで、記事の作成・保存・校正・プレビュー・公開を完了できること。

管理画面

記事管理

一覧、新規作成、Markdown編集、画像、校正、プレビュー、投稿、予約。

スケジュール

記事公開、SNS、発売日、セール終了日を月・週で確認。

AI編集部

検証済み情報から候補3本を提示し、採用から下書きを作成。

リリース・セール

候補を確認・選択して、週次記事の下書きを作成。

SNS

投稿案、人の確認、予約、結果確認を段階的に追加。

アクセス解析

閲覧、検索、流入、記事ごとの7日・30日実績を表示。

実装順

  1. データ構造と移行設計
  2. 管理画面の土台
  3. 記事管理
  4. 記事テンプレート
  5. 校正・プレビュー・公開
  6. ブログデザイン
  7. 予約とカレンダー
  8. アクセス解析
  9. SNS
  10. 共通情報収集
  11. AI編集部
  12. リリース・セール情報

現在維持するもの

Hugoブログ、Page Bundle、校正、プレビュー、公開前検査、GitHub Pages、暗号化バックアップは維持する。

現在保留するもの

Discord通知、週次AI調査、旧週次5選生成、旧Phase 6案は old/ へ退避し、管理画面用に再設計するまで実行しない。
