# 管理画面中心への再構成 実施報告

実施日: 2026-08-09

## 目的

Hugoブログと安全な記事公開機能を残し、Discord、週次AI調査、旧Phase計画を保留して、ローカル管理画面中心の開発へ切り替える。

## 維持した機能

- Hugoブログと既存記事
- 3種類の記事形式
- 校正、プレビュー、公開前検査、記事単位の公開
- GitHub Pagesのビルドとデプロイ
- 日次・月次の暗号化バックアップとWindowsタスク

## 停止・退避した機能

- Discordの公開・注意・エラー通知
- 週次AI候補調査のscheduleと手動workflow
- 週次調査PDFのDiscord送信
- 旧週次5選の候補検証・下書き生成処理
- バックアップ失敗時のDiscord通知
- 旧Phase 6「AI編集長」実装案

コード、ワークフロー、データ、資料は削除せず、当初 `old/`、現在は `archive/` に保存している。GitHub Actionsが認識する `.github/workflows/` にはPages公開用の `hugo.yml` だけを残した。

## バックアップ

バックアップ本体は停止していない。失敗時は外部通知せず、従来どおりローカルの非公開状態記録へ結果を残す。登録済みWindowsタスクの実行先は変更していない。

## 外部変更

外部サービス、GitHub Secrets、Windowsタスク設定、Obsidian設定は変更していない。commit、push、ブログ公開も行っていない。リポジトリの変更はpushされるまでGitHub上のworkflowには反映されない。

## 次の作業

`docs/roadmap.md` のPhase Aとして、記事と画像の正本、既存記事の移行、記事状態、SQLite、復元方法、管理画面と公開処理の境界を設計する。
