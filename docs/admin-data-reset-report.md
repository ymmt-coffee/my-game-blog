# 管理画面データ初期化記録

実施日: 2026-08-22
状態: ローカル初期化済み・公開サイト未反映

## 目的

ブログ更新を1から流れに沿ってテスト運用するため、機能と設定を残したまま、既存の記事と管理画面内の運用データを空にした。

## 初期化したデータ

- 管理原稿 21件
- 公開用記事 7件
- 記事の保存履歴、自動保存、プレビュー、公開準備、校正記録
- 記事状態、予約、公開履歴、操作履歴
- アクセス解析の取込値と取込履歴
- X投稿案と手動投稿記録
- ゲーム情報、候補、情報収集履歴、選定、判断、購入、プレイ評価、記事との関連

About、検索、デザイン、テンプレート、公開処理、外部接続設定など、機能と設定は削除していない。APIキーなどの秘密情報は環境変数にあり、今回の退避対象へ新たに保存していない。

## 復元

初期化前のデータは `var/reset-backups/20260822-133512/` に退避した。ここはGit管理・公開・通常の管理画面表示の対象外である。

- `managed-articles/`: 管理原稿
- `public-posts/`: 公開用記事
- `admin-state/`: SQLite、履歴、自動保存、プレビュー等

復元が必要になった場合は、現在の運用フォルダへ直接上書きせず、別フォルダへコピーして内容を確認してから必要な項目だけを戻す。

## 公開サイトへの反映

ローカルでは公開用記事を空にしたが、公開中のサイトはこの削除をcommit・pushし、GitHub Pagesの更新が成功するまで変わらない。公開反映はユーザーの明示依頼後に行う。
