# Phase F ブログデザイン実装報告

実施日: 2026-08-11

## 決定事項

- 公開ブログは明るいグレーを基調に、黒と深い赤をアクセントにした直線的なゲームメディア風デザインとする。
- ブログ名は今後変更する前提で、当面 `GAME LOGS` とする。
- トップページは最新記事1件を大きく表示し、その後に記事一覧を配置する。
- メニューはプレイ途中記、新作・セール5選、月次レビュー、About、検索とする。
- 広告専用の空白は設けず、広告を追加する場合も後から通常のコンテンツ間へ配置できる構成とする。

## ヘッダー画像

- 管理画面の画像欄へ「ヘッダー画像に設定」と「解除」を追加した。
- 設定内容は標準的なHugo/PaperMod front matterである `cover.image` へ保存する。
- アップロード済みで安全性を確認できた画像だけを選択できる。
- ヘッダー画像がない記事はカテゴリー別の共通表示を使う。
- 本文内に画像があっても、自動でヘッダー画像や一覧サムネイルにはしない。
- 公開済み記事の設定変更は更新下書きとして保存し、既存公開版を維持したまま通常の再投稿手順で反映する。

## 実装内容

- 公開ブログ共通ヘッダー、トップページ、一覧カード、記事ページを更新した。
- カテゴリー名の表示とカテゴリー別の共通ビジュアルを追加した。
- 日本語本文の読みやすさ、PCとモバイルでのレイアウト、ナビゲーションの折り返しを調整した。
- 検索ページと検索用JSON出力を有効にした。
- 管理画面の実装版を Phase F に更新した。

## 安全策

- 本文からの画像抽出や自動選択は行わない。
- ヘッダー画像として存在しないファイルや不正な形式を指定した場合は処理を停止する。
- 設定変更は既存の履歴、競合検出、原子的保存、更新下書きの仕組みを通す。
- この実装作業ではcommit、push、GitHub Pagesへの公開を行わない。

## 確認

- 管理画面の関連テストと回帰テスト
- Hugo本番ビルド
- PC幅とモバイル幅でのトップページ・記事ページの目視確認
- Git差分、秘密情報、PaperMod submoduleの未変更確認

## 公開処理の追加調整

2026-08-11、画像を持たない記事のcommit時に空または存在しない `images/` フォルダを指定して停止する問題を修正した。実画像または追跡済み画像の変更がある場合だけ画像パスをcommit対象へ加え、空フォルダを持つ画像なし記事の再発防止テストを追加した。失敗時のGit待機状態も記事本文と公開コピーを個別に解除する。

同日公開の記事は日付だけでは投稿順を判定できないため、日付が同じ場合は自動slugの `YYYYMMDD-NNN` を降順に使う。これにより、同日の `003` は `002` より新しい記事としてトップへ表示する。

公開済み記事の更新でcommitが失敗した際、命令結果をcommit済みと誤判定して公開用コピーの復元を省略する問題を修正した。commit成功を明示的な真偽値で管理し、失敗時はGitの待機状態を解除して直前の公開コピーを必ず戻すテストを追加した。

復旧処理は公開コピーの変更開始後だけ実行し、バックアップ名変更に失敗した場合はGitに記録された公開版から復元する二段構えとした。想定外例外も黒いInternal Server Error画面にせず、安全停止画面へ変換する。

Windowsで画像を含む公開記事フォルダの名前変更がアクセス拒否になる実環境問題を確認したため、公開前バックアップと復元からフォルダ名変更を廃止した。通常のファイルコピーでバックアップを作成し、失敗時はコピー復元、それも失敗した場合はGit復元を使う。

公開操作の最終確認は独立ページと一回限りの承認情報を維持しつつ、形骸化したslug再入力を廃止した。トップメニューはページ存在確認へ正しいURLを渡し、記事があるカテゴリー、About、検索を表示する。

トップメニューは構成済みの5項目を常時表示する。旧固定ページの広告・アフィリエイト方針、提供作品・レビューキー方針、プライバシーポリシーは現行ブログで不要となったため削除し、検索インデックスにも含めない。Aboutと検索は維持する。
