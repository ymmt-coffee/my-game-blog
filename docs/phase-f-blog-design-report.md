# Phase F ブログデザイン実装報告

実施日: 2026-08-11

## 決定事項

- 公開ブログは明るいグレーを基調に、黒と深い赤をアクセントにした直線的なゲームメディア風デザインとする。
- ブログ名は今後変更する前提で、当面 `GAME LOGS` とする。
- トップページは最新記事1件を大きく表示し、その後に記事一覧を配置する。
- メニューはプレイ途中記、新作・セール5選、月次レビュー、About、検索とする。
- 広告専用の空白は設けず、広告を追加する場合も後から通常のコンテンツ間へ配置できる構成とする。

## ヘッダー画像

- 管理画面の画像欄へ「ヘッダー画像に設定」と「解除」を追加した。
- 設定内容は標準的なHugo/PaperMod front matterである `cover.image` へ保存する。
- アップロード済みで安全性を確認できた画像だけを選択できる。
- ヘッダー画像がない記事はカテゴリー別の共通表示を使う。
- 本文内に画像があっても、自動でヘッダー画像や一覧サムネイルにはしない。
- 公開済み記事の設定変更は更新下書きとして保存し、既存公開版を維持したまま通常の再投稿手順で反映する。

## 実装内容

- 公開ブログ共通ヘッダー、トップページ、一覧カード、記事ページを更新した。
- カテゴリー名の表示とカテゴリー別の共通ビジュアルを追加した。
- 日本語本文の読みやすさ、PCとモバイルでのレイアウト、ナビゲーションの折り返しを調整した。
- 検索ページと検索用JSON出力を有効にした。
- 管理画面の実装版を Phase F に更新した。

## 安全策

- 本文からの画像抽出や自動選択は行わない。
- ヘッダー画像として存在しないファイルや不正な形式を指定した場合は処理を停止する。
- 設定変更は既存の履歴、競合検出、原子的保存、更新下書きの仕組みを通す。
- この実装作業ではcommit、push、GitHub Pagesへの公開を行わない。

## 確認

- 管理画面の関連テストと回帰テスト
- Hugo本番ビルド
- PC幅とモバイル幅でのトップページ・記事ページの目視確認
- Git差分、秘密情報、PaperMod submoduleの未変更確認
