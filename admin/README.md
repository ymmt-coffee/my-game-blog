# ローカルブログ管理画面

Phase Bでは、PC内だけで動く管理画面の土台を提供する。記事の編集や公開はまだ実装していない。

## 起動

デスクトップの「ゲームブログ管理」アイコンを開くと、管理画面を起動して既定ブラウザに表示する。すでに起動中の場合はブラウザ表示だけを行う。

手動で起動する場合は、プロジェクトルートで次を実行する。

```powershell
.\admin\start-admin.ps1
```

ブラウザで `http://127.0.0.1:8765/` を開く。終了は起動した画面で `Ctrl+C`。

デスクトップアイコンで起動した場合は、最小化されている「ゲームブログ管理」用のPowerShell画面を開き、`Ctrl+C` を押すかウィンドウを閉じて終了する。

## 安全性

- 接続先は `127.0.0.1` に固定し、LANやインターネットへ公開しない。
- 同時に複数起動しない。
- 状態DBとログはGit管理外の `var/admin/` に保存する。
- 秘密情報や記事本文を状態DBへ保存しない。
- 記事管理、校正、公開などは後続Phaseまで「準備中」とする。

依存パッケージはプロジェクトルートの `requirements.txt` から導入する。
