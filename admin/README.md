# ローカルブログ管理画面

Phase Eまで実装済み。PC内だけで記事の作成、編集、AI校正、指摘の採否、Hugoプレビュー、公開前チェック、最終確認、記事単位の公開まで行える。

## 起動

デスクトップの「ゲームブログ管理」アイコンを開くと、管理画面を起動して既定ブラウザに表示する。すでに最新版が起動中の場合はブラウザ表示だけを行い、更新前の版が起動中の場合は管理画面のプロセスだけを確認して自動再起動する。

デスクトップアイコンは、UTF-8を正しく扱えるPowerShell 7（`pwsh.exe`）から起動する。

手動で起動する場合は、プロジェクトルートで次を実行する。

```powershell
.\admin\start-admin.ps1
```

ブラウザで `http://127.0.0.1:8765/` を開く。終了は起動した画面で `Ctrl+C`。

デスクトップアイコンから起動したPowerShell画面は表示しない。通常は終了操作も不要で、PC終了時に管理画面も終了する。

## 安全性

- 接続先は `127.0.0.1` に固定し、LANやインターネットへ公開しない。
- 同時に複数起動しない。
- 自動再起動は、`127.0.0.1:8765` を使用する管理画面専用プロセスと確認できた場合だけ行う。別アプリは終了しない。
- 状態DBとログはGit管理外の `var/admin/` に保存する。
- 秘密情報や記事本文を状態DBへ保存しない。
- 必須項目の不足は画面に表示するが、執筆途中の下書き保存は妨げない。
- AI校正は本文を変更せず、結果を `var/admin/reviews/` に保存する。
- 公開は校正鮮度、必須項目、画像、リンク、Hugoビルドを検査し、15分以内の最終確認後だけ実行する。
- 公開時は選択記事の正本と公開コピーだけをstageし、混入を検出したら停止する。

依存パッケージはプロジェクトルートの `requirements.txt` から導入する。
